# RingPad

RingPad is an experimental wearable input system designed to replace laptop trackpad gestures using five smart rings.

## Current progress
- Created the first ring's CAD model in Shapr3D.
- Designed a flat, angular electronics housing.
- Created a recessed cavity for future electronics.
- Explored IMU-based tracking, contact sensing and gesture recognition.

## Planned features
- Finger-controlled cursor
- Tap-to-click and scrolling
- Multi-finger gestures
- Personalised tap-sequence activation
- Five-ring charging case

## Current stage
Early hardware design. No functioning electronics prototype yet.

## Next steps
Select components, test motion sensors, refine the CAD housing and develop gesture-recognition software.
